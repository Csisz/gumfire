# ADR-002 — Integer subpixel units, 50 Hz fixed tick, table trigonometry, seeded RNG streams

Status: accepted (M0) · Plan: §6.3, §7

## Decision
- State is integers only. Positions/velocities in subpixels: **1 px = 256** (`core/units.ts`).
- The sim advances in fixed ticks of **20 ms (50 Hz)** via `step(state, input)`; rendering
  interpolates between the previous and current state.
- Trigonometry uses committed tables (`core/trigTables.ts`, generated by `pnpm gen:trig`):
  4096 angle units per turn, Q16 sine, integer `atan2A`, exact `isqrt`.
- Randomness only from `state.rng`: xoshiro128** seeded by splitmix32, one stream per purpose
  (`mapgen`, `crates`, `wind`, `fuse`, `ai`, `misc`), derived from the match seed + stream name.
- State hash: FNV-1a 32 over a canonical field order (`hashState`).

## Enforcement
ESLint bans `Math.random`, float transcendental `Math.*`, `Date`, `performance`, timers, DOM,
`crypto`, and imports of rendering/UI/net/node modules inside `packages/sim/src`.
`tests/lintRules.test.ts` fails if those rules are removed. Determinism tests run the same
replay twice, across clone and serialise round-trips, and check a golden hash.

## Consequences
Content values in px/seconds/degrees are converted once at load (`toSub`, `secondsToTicks`,
`degToAngle`). Any intentional behaviour change must update golden hashes with a note in
`docs/tuning.md`.
