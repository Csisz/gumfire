# M2 — Terrain destruction

Status: **done** (2026-09-30)

## Objective
Deterministic terrain edits (craters, tunnels, girders) that update collision, hashes and
rendering incrementally, driven through recorded sim commands so they replay exactly.

## Checklist
- [x] `sim/terrain/edit.ts`: `carveCircle` (row spans, isqrt per row), `carveCapsule` (exact
      integer segment distance), `addRect` (fills air only). ROCK/BORDER never change; GIRDER
      only yields to carves with r ≥ 30. Each returns the changed-pixel rect or null.
- [x] Chunk hashes are now position-weighted sums (`pixelWeight`), updated incrementally per
      changed pixel; `carveCircle` accumulates per (row, chunk) segment. Full recompute is only
      for map load. (Golden unaffected: the demo scene has no terrain.)
- [x] Command channel: `SimCommand` (`debugCarve`, `debugTunnel`, `debugGirder`), validated by
      `sanitizeCommand`, max 32 per tick, `step(state, input, commands)`, `TerrainChanged`
      events, `Replay.commands` (tick-stamped).
- [x] Painter damage rendering using the map's original bitmap: back wall behind carved soil,
      scorch ring, frosting only on the original surface. `TerrainView.invalidateRect` for
      events (outline/scorch reach neighbouring chunks).
- [x] Water is fully opaque (no terrain lines showing through).
- [x] Sandbox: click = crater, Shift+click = girder, right-drag = tunnel, `[`/`]` radius,
      `B` = 200 random craters at 10 per tick, cursor preview, HUD with worst step time.
- [x] `pnpm bench:carve`: bundled benchmark (vitest's module transform makes cross-module
      calls ~10× slower, so perf budgets are measured on bundled code).

## Automated tests (83)
Brute-force equivalence for circle and capsule carves, rock/border/girder rules, chunk
bookkeeping vs an independent BigInt recount, incremental = full recompute after mixed edits,
edge clipping, input validation, 300-carve property test, command sanitising, replay with
commands equals the live session; painter back wall / scorch / frosting / partial repaint.

## Manual test (headless Chromium)
3 craters of different sizes, a girder, a tunnel, then the 200-crater stress test (110 hit
terrain, the rest landed in the sky). No hitches in sim time (worst tick 2.9 ms on a cold JIT),
upload queue drained, determinism check passed over 602 ticks with 200+ commands.
