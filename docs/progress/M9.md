# M9 — Full weapon framework

Status: **done** (2026-10-01)

## Objective
Every behaviour block the roster needs, composed from JSON — 10 weapons, no weapon-specific
code paths beyond the generic blocks. Built as delivery + payload + modifiers (Phase 2 hook
26.6 in the master plan).

## Checklist
- [x] Schema (ADR-004 update): categories `ballistic`, `melee`, `hitscan`, `strike`; input
      modes `aimCharge`, `instant`, `target`, `targetCharge`; projectile behaviours `ballistic`,
      `walker`, `boomerang`; triggers `impact`, `fuse`, `remote`; modifiers `bounce`, `homing`;
      payloads `explosion`, `cluster`, `fire`
- [x] Sub-projectiles (cluster bomblets, strike drops) compile to **hidden** defs appended after
      the selectable weapons; they cannot be selected
- [x] `setTarget` command + character target (strikes, homing); targeted weapons refuse to fire
      without one; changing weapon clears it
- [x] Hitscan rays (first character or solid pixel, small blast), multi-shot turns
- [x] Strikes: drops start up-wind of the target, timed with gravity, so they arrive over it
- [x] Cluster payload: bomblets fanned upward with seeded variation (`rng.misc`), flying from
      the next tick (after the parent's crater exists)
- [x] Fire payload + `fires` in the state: flames fall, stick, burn 2 px of ground per pulse
      (they sink in), one damage pulse per character per 10 ticks (no stacking), keep the turn
      from settling until they are out
- [x] Walker: rolls 2 px/tick, climbs ≤ 6 px steps, hops walls, turns round at walls it cannot
      hop
- [x] Remote trigger: Fire detonates; the owner stands still meanwhile; in a match the retreat
      starts after the bang (`match.remoteWait`)
- [x] Homing: after a delay, steers towards the target at a fixed speed and turn rate
- [x] Boomerang: pulled back towards the thrower, strikes each character once (damage + throw),
      caught on return, dropped by terrain
- [x] Content (7 new): Acorn Mortar (cluster), Cookie Roller (walker + remote + fuse), Battery
      Shock Bomb (homing), Sprinkle Drop (strike), Frosting Blaster (fire), Binder-Clip Launcher
      (hitscan ×2), Boomerang Trowel — with the earlier Pepper Rocket, Fizz Grenade, Rolling Pin
- [x] GameState schema 9 (fires, projectile walker/homing/boomerang state, character target,
      `remoteWait`)
- [x] Client: 10 weapon tiles with icons, Q/E to cycle, click the map to place a target (red
      crosshair), "Space: detonate" hint, shot counter for multi-shot; sprites per weapon
      (acorn, cookie, battery, sprinkle, frosting blob, trowel), hitscan beam, flames; new SFX
      (snap, sizzle, whistle)
- [x] Sandbox: PageUp/PageDown cycle weapons, T places a target at the cursor

## Automated tests (195)
New: one fixture per block using the real content JSON — cluster (5 bomblets, parent link, six
blasts), hitscan (first character in line only, terrain hole, two-shot turn), strike (no target
→ nothing; five drops centred on the target), homing (hits within 30 px against wind −100),
walker (lands, rolls 2 px/tick, turns at the wall, Space detonates; owner frozen; match retreat
after the bang; 8 s fuse exact), fire (spawn, ground burn, one damage per pulse, burns out),
boomerang (strikes once, caught; wall drops it), hidden defs unselectable, all ten weapons in one
deterministic session; content compile of 10 + 2 hidden defs with child links.

## Manual test (headless Chromium)

flames, two clip shots, boomerang throw — no errors.
