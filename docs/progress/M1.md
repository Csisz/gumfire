# M1 — Terrain rendering

Status: **done** (2026-09-30)

## Objective
Load 1920×696 maps from PNG masks into the sim's material bitmap and render them with the
chosen flat-vector look, chunked textures and a pan/zoom camera, at 60 fps.

## Checklist

      per-chunk hashes, dirty flags, mask classification, hashing into `hashState`

## Automated tests (63)
Terrain basics (partial edge chunks, bounds, counts, invalid data, mask classes), hash + dirty
tracking, RLE/typed-array serialisation, full-state round-trip with a map, clone isolation,
hash depends on terrain and water; camera maths; painter (outline, frosting, rock, partial
repaint equals full paint, determinism, full-map paint speed); plus all M0 tests.

## Manual test (headless Chromium, software GL)
Both maps load (decode ≈ 50–65 ms, full paint 30–80 ms). Zoom 70 %→250 % around the cursor,
drag pan, keyboard pan all work; no chunk seams. `U` queued 306 chunks and drained them at 24
per frame. Determinism check passes on map scenes and the bouncers scene. No console errors.
(fps in the headless run is software rendering; confirm 60 fps on a real GPU.)
