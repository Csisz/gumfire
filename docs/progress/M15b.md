# M15b — CPU opponents

Status: **done** (2026-10-03)

## Checklist
- [x] `packages/ai`: turn planner (predict → play out), scripts of input frames, `AiPlayer`
      controller (ADR-007)
- [x] Three levels: **easy** (3 weapons, coarse aim, wobbly, shoots from where it stands),
      **normal** (7 weapons, hitscan / melee / strikes, walks towards the enemy, small wobble),
      **hard** (every attack weapon, walks either way first, refines its best shot, exact)
- [x] Uses ballistic weapons (wind, bounces, fuses 1–5, sticky, cluster, fire), homing with a
      target, air strikes, hitscan guns and melee; ends its own retreat; naps when nothing helps
- [x] Never prefers a shot that hurts its own team more than the enemy
- [x] Client: **Quick match vs CPU** on the title screen with a difficulty choice; in the match
      setup every team can be a player or a CPU (CPU vs CPU works too)
- [x] The search runs in a Web Worker; the HUD says "CPU is thinking…" / "CPU's move"; the
      keyboard, weapon panel and target clicks are ignored during CPU turns
- [x] CPU turns replay exactly from the recorded inputs (test)
- [x] `tools/ai/arena.ts`: CPU-vs-CPU and CPU-vs-idle matches with think-time stats
