# M0 — Technical sandbox

Status: **done** (2026-09-30)

## Objective
A green monorepo with the deterministic simulation core, enforced determinism rules, and a
sandbox that runs the sim at 50 Hz with render interpolation.

## Checklist
- [x] pnpm workspace, TypeScript strict, ESLint, Vitest, CI workflow
- [x] `core/units.ts` — subpixels (×256), fixed-point mul/div, ticks
- [x] `core/trig.ts` + generated `trigTables.ts` — sin/cos Q16, `atan2A`, exact `isqrt`
- [x] `core/rng.ts` — xoshiro128** (verified against reference vector), independent named streams
- [x] `core/hash.ts` — FNV-1a (verified against known vectors), canonical `hashState`
- [x] `core/input.ts` — 16-bit input frames
- [x] `core/clone.ts` — platform-independent deep clone (typed-array aware)
- [x] `GameState`, `createGame`, `step`, serialise/deserialise, `runReplay`
- [x] ESLint determinism ban-list for `packages/sim`, with a test that the rules stay on
- [x] Sandbox: Vite + PixiJS, `FixedStepLoop` (unit-tested), interpolation toggle, pause/step,
      input recording, one-click headless replay verification
- [x] ADR-001, ADR-002

## Automated tests (37)
Units, trig accuracy over all 4096 angles, isqrt exactness, hash vectors, RNG reference vector /
uniformity / stream independence, determinism (repeat, seed divergence, single-input divergence,
clone, serialise round-trip, integer-only state, golden hash), fixed-step loop at 30/60/144 fps
and stall handling, lint-rule enforcement.

## Manual test
Sandbox opened in headless Chromium: bodies spawn/push/kick, interpolation smooth, step cost
≈ 10 µs/tick with 12 bodies, "Verify determinism" replayed 234 ticks headless in ~1 ms with a
matching hash. No console errors (favicon 404 fixed).
